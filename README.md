# May-O Desktop — descargas

Aquí se publican los instaladores de **May-O Desktop** para Windows. La app se
actualiza sola desde este repositorio.

**[Descargar la última versión](https://github.com/iangelmanuel/may-o-desktop-releases/releases/latest)**
(`May-O-Setup-x.y.z.exe`).

Windows puede mostrar «Editor desconocido» porque la app todavía no está
firmada: elige **Más información → Ejecutar de todas formas**.

La web: <https://may-o.vercel.app>
